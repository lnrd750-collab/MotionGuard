# MotionGuard

## Sistema Inteligente de Analise de Postura para Agachamento utilizando Visao Computacional ##

Tecnologias Utilizadas
Python 3.10
OpenCV
MediaPipe
NumPy
Funcionalidades
Deteccao corporal em tempo real
Calculo do angulo do joelho
Analise da postura durante o agachamento
Contagem automatica de repeticoes
Validacao de enquadramento corporal
Como Executar

Instale as dependencias:

pip install -r requirements.txt

Execute:

python analisador_agachamento.py
